# OMN-058 — Factory unilateral exits enforce the original funding shares, not the latest signed factory state

**Kind:** sdk-defect  
**Severity:** critical  
**Status:** open  
**Packages:** `@totemsdk/omnia-factory`
**Observed versions:** @totemsdk/omnia@3.0.0, @totemsdk/omnia-host@0.14.0, @totemsdk/omnia-factory@0.7.2, @totemsdk/wots-lease@0.5.0
**Origin:** Totem Edge Omnia whole-family re-audit, 2026-11-17 @ `c81af31` (verified in source)
**Source:** `Deeper Omnia covenant/transaction audit, 2026-11-18 (verified against 51aed956)`

## Context

buildFactoryOpening writes each participant original contribution into the funding coin share ports, and the timeout branch pays those ports. Virtual-channel opens, updates and closes change allocations off-chain with N-of-N signatures, but nothing updates the on-chain share ports or pre-signs a distribution transaction for the new allocation, so the escape still pays the original split.

## Impact

After an escape opens, a participant could reclaim their original allocation despite having transferred value away in signed virtual-channel updates. The recipient newer entitlement is not enforceable on chain.

## Reproduce

```bash
pnpm --filter @totemsdk/omnia-factory test
```

**Expected:** Every committed factory transition has an enforceable recovery artifact for its latest allocation.

**Actual:** Only the immutable initial split is enforceable by the escape covenant.

**Evidence:**

- packages/omnia-factory/src/factory.ts buildFactoryOpening
- packages/omnia-factory/src/script.ts escape branch
- packages/omnia-factory/src/virtual.ts allocations

## Where to fix

- `packages/omnia-factory/src/factory.ts`
- `packages/omnia-factory/src/script.ts`
- `packages/omnia-factory/src/virtual.ts`

### Approach

Give every committed transition a presigned, independently broadcastable distribution (eltoo-style) or a covenant that verifies the latest authorized state before paying escape shares.

## Constraints (do not violate)

- An immutable initial-share escape is insufficient for a changing ledger.
- Do not claim factory value is enforceable until the artifact exists and is tested.

## Acceptance criteria

- [ ] A signed virtual-channel payment is enforceable by the losing party on chain.
- [ ] Escape pays the latest signed allocation, not the original contribution.
