# CAN-008 — Forwarder signs the outgoing HTLC before the link is durable

**Kind:** sdk-defect  
**Severity:** high  
**Status:** fixed  
**Packages:** `@totemsdk/omnia-relay`
**Observed versions:** @totemsdk/omnia-relay@0.7.1
**Source:** `security audit OMN-NEW-002, verified against source at 8fa26907`

## Context

forwardIncoming calls addHTLC (which reserves WOTS keys and signs the new state), writes the updated channel into the channel map, builds the link record, and only then calls linkJournal.record(). A crash or a storage failure between the signed state and the journal write leaves an outgoing obligation with no durable incoming-to-outgoing association.

## Impact

Stranded liquidity and broken backward settlement after a restart: the relay knows it signed an outgoing HTLC on-chain-ish state but cannot reconstruct which incoming HTLC it was forwarding. Contradicts the durability claim the recovery design rests on.

## Reproduce

```bash
pnpm --filter @totemsdk/omnia-relay test
```

**Expected:** The association is durable before or atomically with the signed outgoing state, so recovery can always pair an outgoing HTLC with its incoming one.

**Actual:** record() runs after addHTLC() and after channels.set(); a failure in between is unrecoverable.

**Evidence:**

- fix proposed in PR #218 (intent journaled before signing; recovery completes or drops it)
- packages/omnia-relay/src/forwarder.ts:203 — addHTLC(outChannel, ...)
- packages/omnia-relay/src/forwarder.ts:219 — options.channels.set(result.channel.channelId, result.channel)
- packages/omnia-relay/src/forwarder.ts:231 — await options.linkJournal.record(link)

## Where to fix

- `packages/omnia-relay/src/forwarder.ts`

### Approach

Write an intent record before signing (hashlock, incoming ids, planned outgoing channel/amount/timeout), then sign, then commit the outgoing htlc id. Recovery resolves intents: if the outgoing htlc exists, complete the link; if not, the intent is safe to drop.

## Constraints (do not violate)

- Do not claim durability for a link that was not written before the signature.
- Do not make the journal the authority for channel balances.

## Acceptance criteria

- [ ] A crash injected between signing and commit leaves a recoverable record.
- [ ] recover() can reconstruct the link from the intent plus channel state.
- [ ] Normal forwarding writes the same number of journal entries.
