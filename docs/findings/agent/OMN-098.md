# OMN-098 — A channel is funded before either party holds a unilateral exit package

**Kind:** sdk-defect  
**Severity:** critical  
**Status:** fixed  
**Packages:** `@totemsdk/omnia`, `@totemsdk/omnia-host`, `@totemsdk/omnia-lsp-provider`
**Observed versions:** @totemsdk/omnia@4.0.0, @totemsdk/omnia-host@0.16.0, @totemsdk/omnia-lsp-provider@0.2.0
**Origin:** Omnia adversarial audit — 26 November 2026 @ `c818f5e` (verified in source)

> reporter id OMN-096; fixed by making a co-signed sequence-0 state with a verified close package a precondition of the funding broadcast: the opening handshake exchanges CHANNEL_OPEN_COSIGN/REPLY before funding, finalizeChannelOpening verifies the state and close package and refuses otherwise, and local-dev opens require an explicit flag (RFC-082)
**Source:** `Omnia adversarial audit — 26 November 2026, reporter finding OMN-096 (omnia/src/channel.ts:167-198, channel.ts:234-325, settlement.ts:417-433)`

## Context

The opening builder creates the channel with latestState null and sequence 0, then funding is broadcast. startUnilateralClose requires a signed state carrying a valid close package, so during the opening window the funding coin exists on chain with no independent recovery path.

## Impact

If the counterparty disappears or refuses to co-sign the first state, the capital is stranded behind cooperation. Provider-funded LSP channels carry this exposure for the provider.

## Reproduce

```bash
pnpm --filter @totemsdk/omnia test
```

**Expected:** Funding broadcast requires an initial, fully signed state with a verified close package.

**Actual:** latestState is null at funding; the close package arrives only after a cooperative update.

**Evidence:**

- channel.ts:186-188 (latestState: null, currentSequence: 0)
- settlement.ts:426-431 (close package required to close)

## Where to fix


### Approach

Make a signed sequence-0 state with a verified close package a precondition of the funding broadcast, and persist it before broadcasting.

## Constraints (do not violate)

- Do not weaken the close-package verification.
- Keep the proposal flow usable: the initial state can travel with the proposal.

## Acceptance criteria

- [ ] A funding broadcast without a persisted close package is refused.
- [ ] A restart after funding can always start a unilateral close.
