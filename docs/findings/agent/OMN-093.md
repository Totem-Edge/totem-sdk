# OMN-093 — Fulfilment and timeout are both eligible at the exact timeout block

**Kind:** sdk-defect  
**Severity:** high  
**Status:** fixed  
**Packages:** `@totemsdk/omnia`
**Observed versions:** @totemsdk/omnia@3.0.0
**Origin:** Omnia SDK audit — 25 November 2026 @ `9f882c8` (verified in source)
**Source:** `Omnia SDK audit — 25 November 2026, reporter finding OMN-091`

## Context

fulfillHTLC() refuses only when tip.block > htlc.timeoutBlock; timeoutHTLC() refuses only when tip.block < htlc.timeoutBlock. At exactly timeoutBlock both transitions pass their SDK-level guard, so the two branches of the same HTLC overlap for one block.

## Impact

Two parties can each believe their transition is valid at the same height. The on-chain script decides the real boundary, so the SDK can co-sign a state the deployed KISSVM contract rejects, or accept a conflicting claim it should have refused.

## Reproduce

```bash
cd artifacts/canary && pnpm run canary run 11-omnia-direct-channel
```

**Expected:** Exactly one transition is eligible at every height, matching the deployed script.

**Actual:** At tip.block == timeoutBlock both fulfillHTLC and timeoutHTLC proceed past their guards.

**Evidence:**

- packages/omnia/src/htlc.ts:316 — if (BigInt(tip.block) > htlc.timeoutBlock) throw
- packages/omnia/src/htlc.ts:436 — if (currentBlock < htlc.timeoutBlock) throw

## Where to fix

- `packages/omnia/src/htlc.ts`
- `packages/omnia-factory/src/script.ts`

### Approach

Adopt one canonical boundary rule that matches the deployed KISSVM comparison, expose it as a single shared predicate, and apply it in every package that reasons about HTLC expiry.

## Constraints (do not violate)

- The rule must match the on-chain script exactly; derive it from the script, not from a preference.
- Do not leave two implementations of the boundary.
- Changing the boundary is a wire/behaviour change: note it in the changelog.

## Acceptance criteria

- [ ] At most one of fulfil/refund is eligible at any height.
- [ ] The SDK boundary and the deployed script agree at the critical block.
- [ ] One exported predicate is used everywhere the boundary is evaluated.
