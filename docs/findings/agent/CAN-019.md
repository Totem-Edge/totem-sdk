# CAN-019 — Finalization guards validate identifiers, not the resulting state

**Kind:** sdk-defect  
**Severity:** high  
**Status:** open  
**Packages:** `@totemsdk/omnia-host`
**Observed versions:** @totemsdk/omnia-host@0.13.4
**Source:** `re-audit R-002, verified against source at 5d8c427b`

## Context

CAN-007 stopped unsolicited finalizations by requiring a local acceptance. But assertSpliceFinalized checks ids (spliceId, channelId, splicedFrom, txId) and assertVcFinalized checks kind, factory and a one-step sequence. Neither compares balances, totalValue or allocations with the locally signed proposal. Separately, FACTORY_CLOSE_FINALIZED marks a known factory closed with no settlement check.

## Impact

A counterparty can finalize a transition whose economic terms differ from what was accepted, as long as the identifiers line up. A factory can be marked closed without proof that settlement happened.

## Reproduce

```bash
pnpm --filter @totemsdk/omnia-host test
```

**Expected:** The finalized channel/factory is compared field-by-field with the accepted proposal, including balances, totalValue and allocations, and signatures over that state verify.

**Actual:** Only identifiers and the sequence step are compared.

**Evidence:**

- packages/omnia-host/src/peer-guards.ts — assertSpliceFinalized compares ids and txId only
- packages/omnia-host/src/peer-guards.ts — assertVcFinalized compares factoryId and sequence only
- packages/omnia-host/src/lifecycle.ts:459-462 — FACTORY_CLOSE_FINALIZED sets status closed without settlement evidence

## Where to fix

- `packages/omnia-host/src/peer-guards.ts`
- `packages/omnia-host/src/lifecycle.ts`

### Approach

Pass the locally accepted proposal/acceptance into the guards and compare the complete finalized state (balances, totalValue, allocations, virtual-channel set) plus the signatures over it. Require settlement evidence before a factory is marked closed.

## Constraints (do not violate)

- Do not weaken the existing id checks.
- Do not accept a finalized state that differs in any economically meaningful field.

## Acceptance criteria

- [ ] A finalized splice with altered balances is rejected.
- [ ] A VC finalization whose allocations differ from the signed plan is rejected.
- [ ] FACTORY_CLOSE_FINALIZED without settlement evidence does not close the factory.
