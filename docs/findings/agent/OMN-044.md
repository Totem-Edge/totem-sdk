# OMN-044 — Unauthenticated route advertisements could poison the routing graph

**Kind:** sdk-defect  
**Severity:** medium  
**Status:** fixed  
**Packages:** `@totemsdk/omnia-host`, `@totemsdk/omnia-router`
**Observed versions:** @totemsdk/omnia@3.0.0, @totemsdk/omnia-host@0.14.0, @totemsdk/omnia-factory@0.7.2, @totemsdk/omnia-vtxo@0.9.0, @totemsdk/omnia-pool@0.6.0, @totemsdk/liquidity-bond@0.4.0, @totemsdk/omnia-router@0.4.2, @totemsdk/tx-builder@0.7.0
**Origin:** Totem Edge Omnia whole-family re-audit, 2026-11-17 @ `c81af31` (verified in source)
**Source:** `Deeper Omnia host audit, 2026-11-18 (verified against 51aed956)`

## Context

The host accepted ROUTE_GRAPH_ANNOUNCE edges without checking that the announcer participates in the claimed channel or that the channel exists, then merged them into the live router. Announcements are now authenticated against local channels, endpoints and token are bound to that channel, economic fields are clamped to real capacity, size and age are bounded, and only authenticated edges are re-gossiped.

## Impact

A peer could advertise nonexistent capacity and make route discovery return unusable paths.

## Reproduce

```bash
pnpm --filter @totemsdk/omnia-host test
```

**Expected:** Announcements are authenticated and validated against real channels.

**Actual:** Fixed: unknown channels, foreign announcers, inflated capacity and oversized batches are ignored.

**Evidence:**

- packages/omnia-host/src/lifecycle.ts ROUTE_GRAPH_ANNOUNCE handler
- packages/omnia-host/src/router/routing-provider.ts rebuild

## Where to fix

- `packages/omnia-host/src/lifecycle.ts`

### Approach

Authenticate announcements, bind them to real channel participants, clamp economic fields, bound age/size, and re-gossip only authenticated edges.

## Constraints (do not violate)

- Do not treat unverified advertisements as executable capacity.

## Acceptance criteria

- [ ] Unknown or foreign channel announcements are ignored.
- [ ] Inflated capacity is clamped.
- [ ] Oversized batches are dropped.

## Tests that prove it
