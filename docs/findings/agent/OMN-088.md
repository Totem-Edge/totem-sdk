# OMN-088 — createExitDraft returns a receipt without consuming it

**Kind:** sdk-defect  
**Severity:** high  
**Status:** fixed  
**Packages:** `@totemsdk/omnia-vtxo`
**Observed versions:** @totemsdk/omnia-vtxo@0.9.0
**Origin:** Omnia SDK audit — 25 November 2026 @ `9f882c8` (verified in source)
**Source:** `Omnia SDK audit — 25 November 2026, reporter finding OMN-086`

## Context

The doc comment says createExitDraft consumes the VTXO's receipt so a second exit draft is refused. The implementation checks exitConsumedAt, builds a draft and returns a receipt; consumption requires a separate consumeExitReceipt call that nothing forces.

## Impact

Repeated calls generate competing exit drafts for the same VTXO. The underlying UTXO cannot be double-spent, so this is not a fund-loss path, but the SDK-level single-exit guarantee the API advertises does not hold, and callers that skip the second call get two drafts they may act on independently.

## Reproduce

```bash
pnpm --filter @totemsdk/omnia-vtxo test
```

**Expected:** One call atomically reserves the exit against the authoritative VTXO store; a repeat returns the original draft.

**Actual:** createExitDraft can be called twice in a row against the same VTXO object and returns two receipts.

**Evidence:**

- packages/omnia-vtxo/src/exit.ts:83-133 — createExitDraft
- packages/omnia-vtxo/src/exit.ts:136-148 — consumeExitReceipt is a separate opt-in call

## Where to fix

- `packages/omnia-vtxo/src/exit.ts`

### Approach

Make creation reserve the exit atomically (store-backed) and return the existing draft on a repeat request rather than a new one. Deprecate the two-step API or make the separate call a no-op once reserved.

## Constraints (do not violate)

- Repeated requests must be idempotent, not error-and-forget.
- Reservation must be durable across a restart.
- Do not change the receipt id derivation for an existing draft.

## Acceptance criteria

- [ ] A second createExitDraft returns the first draft and receipt.
- [ ] A VTXO with a reserved exit cannot produce a competing draft.
- [ ] The reservation survives a restart.
