# OMN-042 — VTXO exits could be marked complete without proving a payout

**Kind:** sdk-defect  
**Severity:** high  
**Status:** fixed  
**Packages:** `@totemsdk/omnia-host`, `@totemsdk/omnia-vtxo`
**Observed versions:** @totemsdk/omnia@3.0.0, @totemsdk/omnia-host@0.14.0, @totemsdk/omnia-factory@0.7.2, @totemsdk/omnia-vtxo@0.9.0, @totemsdk/omnia-pool@0.6.0, @totemsdk/liquidity-bond@0.4.0, @totemsdk/omnia-router@0.4.2, @totemsdk/tx-builder@0.7.0
**Origin:** Totem Edge Omnia whole-family re-audit, 2026-11-17 @ `c81af31` (verified in source)
**Source:** `Deeper Omnia host audit, 2026-11-18 (verified against 51aed956)`

## Context

completeVtxoExit called markExited with an optional caller txpowId; neither the host nor markExited checked the exit transaction, funding coin, payout or confirmations. Completion now requires a mandatory transaction id and a trusted verifier that confirms owner, amount, token and depth; the VTXO stays exiting otherwise.

## Impact

The VTXO ledger could report settlement finality with no corresponding payment.

## Reproduce

```bash
pnpm --filter @totemsdk/omnia-host test
```

**Expected:** Exit completion requires verified chain evidence.

**Actual:** Fixed: completeVtxoExit requires a verifier and markExited requires a transaction id.

**Evidence:**

- packages/omnia-host/src/api/methods.ts completeVtxoExit
- packages/omnia-vtxo/src/exit.ts markExited

## Where to fix

- `packages/omnia-host/src/api/methods.ts`
- `packages/omnia-vtxo/src/exit.ts`
- `packages/omnia-vtxo/src/types.ts`

### Approach

Require a trusted verifier for the exact exit transaction, funding input, owner output, amount/token and depth; keep exiting until verified.

## Constraints (do not violate)

- No caller assertion may finalize an exit.

## Acceptance criteria

- [ ] An unverified exit stays exiting.
- [ ] A verified exit becomes exited.
- [ ] A wrong owner or shallow confirmation is rejected.

## Tests that prove it
