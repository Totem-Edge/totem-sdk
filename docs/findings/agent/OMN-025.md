# OMN-025 — Exit entitlements still do not prove the witness or the authoritative pool coin

**Kind:** sdk-defect  
**Severity:** high  
**Status:** open  
**Packages:** `@totemsdk/omnia-vtxo`
**Observed versions:** @totemsdk/omnia@3.0.0, @totemsdk/omnia-host@0.14.0, @totemsdk/omnia-factory@0.7.2, @totemsdk/omnia-splice@0.3.4, @totemsdk/omnia-vtxo@0.9.0
**Origin:** Totem Edge Omnia whole-family re-audit, 2026-11-17 @ `c81af31` (verified in source)
**Source:** `Omnia host signing audit, 2026-11-18 (verified against 997b7f40)`

## Context

verifyVtxoExitEntitlement now checks the proof root/epoch, decodes the exit transaction, checks the payout address/amount and the funding input. It still does not decode/verify witness signatures or proofs, makes the digest optional (skipping transaction checks when absent), and never anchors the funding coin/exit delay to live or proven historical pool state.

## Impact

A caller can still supply internally consistent metadata plus an unverified witness and have the helper accept an exit that does not actually provide the promised payout, unless a separate verifier checks the chain proof.

## Reproduce

```bash
pnpm --filter @totemsdk/omnia-vtxo test
```

**Expected:** The exit transaction and witness are rebuilt/verified against trusted pool and owner state, with a mandatory digest.

**Actual:** Transaction shape is checked only when digest is present; witnessHex only has to be non-empty.

**Evidence:**

- packages/omnia-vtxo/src/exit-entitlement.ts verifyVtxoExitEntitlement
- packages/omnia-vtxo/src/exit.ts createExitDraft

## Where to fix

- `packages/omnia-vtxo/src/exit-entitlement.ts`
- `packages/omnia-vtxo/src/exit.ts`

### Approach

Require a digest, rebuild the canonical exit transaction from trusted pool/owner state, compare every committed field, decode and verify the witness, and anchor the funding coin and exit delay to the pool (live or historical).

## Constraints (do not violate)

- Do not accept a missing digest as a bypass.
- Do not trust the entitlement to describe its own pool state.
- Keep historical-epoch proofs verifiable.

## Acceptance criteria

- [ ] A missing/different digest is rejected.
- [ ] The witness is verified and the funding coin/exit delay are anchored.
- [ ] A valid pool exit still passes.

## Verification (run before opening a PR)

```bash
pnpm --filter @totemsdk/omnia-vtxo test
```
