# OMN-030 — Liquidity deposits can be credited against a coin that does not belong to the claimed LP

**Kind:** sdk-defect  
**Severity:** high  
**Status:** fixed  
**Packages:** `@totemsdk/omnia-host`, `@totemsdk/omnia-pool`, `@totemsdk/liquidity-bond`
**Observed versions:** @totemsdk/omnia@3.0.0, @totemsdk/omnia-host@0.14.0, @totemsdk/omnia-factory@0.7.2, @totemsdk/omnia-splice@0.3.4, @totemsdk/omnia-vtxo@0.9.0, @totemsdk/omnia-pool@0.6.0, @totemsdk/liquidity-bond@0.4.0, @totemsdk/chain-provider@0.4.0
**Origin:** Totem Edge Omnia whole-family re-audit, 2026-11-17 @ `c81af31` (verified in source)
**Source:** `Deeper Omnia host audit, 2026-11-18 (verified against 41106016 / 997b7f4)`

## Context

The host deposit verifier checked existence, spent state, token and amount only. It now delegates to chainProvider.verifyDeposit when available (owner address, token, amount, confirmation) and otherwise checks owner address and a positive MMR entry before accepting the commitment.

## Impact

A claimant could previously present an unrelated observable coin and receive a position/receipt without proving ownership.

## Reproduce

```bash
npx jest --config tests/jest/omnia-host.cjs --runInBand tests/unit/omnia-host/src/__tests__/pool.test.ts
```

**Expected:** A coin whose address is not the claimed LP address is rejected.

**Actual:** Fixed: the deposit verifier compares the coin owner and requires chain confirmation.

**Evidence:**

- packages/omnia-host/src/api/methods.ts depositToLiquidityPool
- packages/liquidity-bond/src/commitment.ts claimedAmount/lpAddress contract

## Where to fix

- `packages/omnia-host/src/api/methods.ts`

### Approach

Use the real chain-provider deposit contract (owner/token/amount/confirmation) and fail closed; do not substitute a narrower check through a cast.

## Constraints (do not violate)

- Never accept a coin without matching ownership and confirmation evidence.

## Acceptance criteria

- [ ] Wrong-owner coin is rejected before a position is created.
- [ ] The honest LP coin still deposits.
