# OMN-034 — Factory and VTXO unilateral escape share ports were serialized at scale zero

**Kind:** sdk-defect  
**Severity:** critical  
**Status:** fixed  
**Packages:** `@totemsdk/omnia-factory`, `@totemsdk/omnia-vtxo`, `@totemsdk/omnia`
**Observed versions:** @totemsdk/omnia@3.0.0, @totemsdk/omnia-host@0.14.0, @totemsdk/omnia-factory@0.7.2, @totemsdk/omnia-splice@0.3.4, @totemsdk/omnia-vtxo@0.9.0, @totemsdk/omnia-pool@0.6.0, @totemsdk/liquidity-bond@0.4.0, @totemsdk/chain-provider@0.4.0
**Origin:** Totem Edge Omnia whole-family re-audit, 2026-11-17 @ `c81af31` (verified in source)
**Source:** `Deeper Omnia host audit, 2026-11-18 (verified against 41106016 / 997b7f4)`

## Context

factoryBalanceStateVariables and poolStateVariables stored share/contribution atoms at state ports 128+k with no MiniNumber scale. The escape scripts use those ports as exact payout amounts, so a 0.2 MINIMA share was read as 2e43 MINIMA and the unilateral exit could not be satisfied. Both builders now emit scale 44, matching coin amounts.

## Impact

Unilateral escape is the recovery path when counterparties disappear; a fractional share made it unsatisfiable.

## Reproduce

```bash
npx jest --config tests/jest/omnia-factory.cjs --runInBand tests/unit/omnia-factory/src/__tests__/factory.test.ts && npx jest --config tests/jest/omnia-vtxo.cjs --runInBand tests/unit/omnia-vtxo/src/__tests__/anchor.test.ts
```

**Expected:** Share state serializes with scale 44 so PREVSTATE(128+k) equals the coin amount.

**Actual:** Fixed in both state builders; fractional-scale assertions added.

**Evidence:**

- packages/omnia-factory/src/script.ts factoryBalanceStateVariables
- packages/omnia-vtxo/src/anchor.ts poolStateVariables
- packages/omnia/src/transactions.ts state scale default

## Where to fix

- `packages/omnia-factory/src/script.ts`
- `packages/omnia-vtxo/src/anchor.ts`

### Approach

Apply MINIMA_DECIMALS to every on-chain state port representing a monetary amount, and add fractional KISSVM/escape tests.

## Constraints (do not violate)

- Do not change script wire formats beyond the state scale.
- Every value port must share the coin amount scale.
