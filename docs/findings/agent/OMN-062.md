# OMN-062 — VTXO on-chain spending helpers broadcast without required proofs

**Kind:** sdk-defect  
**Severity:** high  
**Status:** fixed  
**Packages:** `@totemsdk/omnia-vtxo`
**Observed versions:** @totemsdk/omnia@3.0.0, @totemsdk/omnia-host@0.14.0, @totemsdk/omnia-factory@0.7.2, @totemsdk/omnia-vtxo@0.9.0, @totemsdk/omnia-pool@0.6.0, @totemsdk/liquidity-bond@0.4.0, @totemsdk/omnia-router@0.4.2, @totemsdk/omnia-splice@0.3.4, @totemsdk/chain-provider@0.4.0, @totemsdk/core@1.6.0
**Origin:** Totem Edge Omnia whole-family re-audit, 2026-11-17 @ `c81af31` (verified in source)
**Source:** `Deeper Omnia covenant/transaction audit, 2026-11-18 (verified against 51aed956)`

## Context

Anchor, per-share exit and owner-pool transactions treated coin/script proofs as optional and broadcast an empty witness. All three now refuse to broadcast unless proofs are supplied.

## Impact

Malformed recovery transactions could be produced and submitted.

## Reproduce

```bash
pnpm --filter @totemsdk/omnia-vtxo test
```

**Expected:** Broadcasting without proofs is rejected.

**Actual:** Fixed: assertBroadcastProofs gates every broadcast path.

**Evidence:**

- packages/omnia-vtxo/src/anchor.ts
- packages/omnia-vtxo/src/exit-tx.ts
- packages/omnia-vtxo/src/owner-pool.ts

## Where to fix

- `packages/omnia-vtxo/src/anchor.ts`
- `packages/omnia-vtxo/src/exit-tx.ts`
- `packages/omnia-vtxo/src/owner-pool.ts`

### Approach

Require proofs for every spending input before broadcasting.

## Constraints (do not violate)

- Offline draft generation may still omit them.

## Acceptance criteria
