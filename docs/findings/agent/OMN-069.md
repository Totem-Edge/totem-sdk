# OMN-069 — Manifest freshness is decided with a caller-supplied clock

**Kind:** sdk-defect  
**Severity:** high  
**Status:** fixed  
**Packages:** `@totemsdk/omnia-lsp-provider`
**Observed versions:** @totemsdk/omnia-lsp-provider@0.1.0
**Origin:** Omnia SDK audit — 25 November 2026 @ `9f882c8` (verified in source)
**Source:** `Omnia SDK audit — 25 November 2026, reporter finding OMN-067`

## Context

evaluateOpenRequest() reads `request.now` and falls back to Date.now(). The expiry check that protects the provider is therefore under the requester's control: an expired manifest can be made to look current by setting now to a past timestamp.

## Impact

The provider can be made to serve terms it has withdrawn. The same field is also carried through the open request type, so the attack needs no special access.

## Reproduce

```bash
pnpm --filter @totemsdk/omnia-lsp-provider test
```

**Expected:** Freshness is decided by the provider's trusted clock; a time source is injectable for tests through configuration only.

**Actual:** evaluateOpenRequest(manifest, { ...request, now: 1 }) treats a manifest whose expiresAt is in the past as valid.

**Evidence:**

- packages/omnia-lsp-provider/src/policy.ts:74 — const now = request.now ?? Date.now()

## Where to fix

- `packages/omnia-lsp-provider/src/policy.ts`
- `packages/omnia-lsp-provider/src/provider.ts`

### Approach

Remove `now` from the public request type. Thread the provider clock (already available as config.now in createOmniaLspProvider) into evaluateOpenRequest as an explicit parameter.

## Constraints (do not violate)

- Keep deterministic tests possible via the config clock.
- Do not silently ignore a caller-supplied now: reject the field if it is still accepted structurally.

## Acceptance criteria

- [ ] A request cannot influence the manifest expiry check.
- [ ] The facade's clock injection still works for tests.
- [ ] The public request type no longer exposes a time source.
