# OMN-070 — Host adapter reports success for an undefined, malformed or error-only response

**Kind:** sdk-defect  
**Severity:** high  
**Status:** fixed  
**Packages:** `@totemsdk/omnia-lsp-provider`
**Observed versions:** @totemsdk/omnia-lsp-provider@0.1.0
**Origin:** Omnia SDK audit — 25 November 2026 @ `9f882c8` (verified in source)
**Source:** `Omnia SDK audit — 25 November 2026, reporter finding OMN-068`

## Context

createOmniaHostProviderHost() defines success as `result?.success !== false`. An undefined return, a response object with no success field, or an object carrying only an error is therefore classified as a successful open or close.

## Impact

A failed or unrecognised host response is reported to the consumer as success, so the LSP layer believes a channel exists (or was closed) when it does not. Callers that key funding or accounting off this flag act on a false positive.

## Reproduce

```bash
pnpm --filter @totemsdk/omnia-lsp-provider test
```

**Expected:** Success requires an explicit success flag plus operation-specific evidence: a channelId for open, a terminal lifecycle state for close.

**Actual:** A handler returning undefined, {}, or { error: 'boom' } is reported as { success: true }.

**Evidence:**

- packages/omnia-lsp-provider/src/host.ts:104-110 — success: result?.success !== false (open)
- packages/omnia-lsp-provider/src/host.ts:135-139 — same rule for close

## Where to fix

- `packages/omnia-lsp-provider/src/host.ts`

### Approach

Require result.success === true and, for open, a non-empty channelId; for close, a status that proves the channel reached a closing/closed state. Treat a non-object response as HOST_PROTOCOL_ERROR.

## Constraints (do not violate)

- Fail closed on an unrecognised response shape.
- Do not invent a channelId when the host omitted one.
- Preserve errorCode passthrough so callers can distinguish causes.

## Acceptance criteria

- [ ] undefined, null, non-object and error-only responses are failures.
- [ ] open success without a channelId is a failure.
- [ ] A malformed host result cannot reach the consumer as success.
