# OMN-085 — Forwarding compares amounts across assets without an exchange-rate authorization

**Kind:** sdk-defect  
**Severity:** high  
**Status:** fixed  
**Packages:** `@totemsdk/omnia-relay`
**Observed versions:** @totemsdk/omnia-relay@0.10.0
**Origin:** Omnia SDK audit — 25 November 2026 @ `9f882c8` (verified in source)
**Source:** `Omnia SDK audit — 25 November 2026, reporter finding OMN-083`

## Context

The forward path rejects an outgoing amount greater than the incoming amount without first establishing that the two HTLCs are denominated in the same token. Comparing bare integers across different assets is not an economic check, and a cross-token forward has no authenticated rate at all.

## Impact

A cross-token forward can be admitted on a meaningless numeric comparison, so the intermediary can pay out more value than it took in. Nothing in the journal records what rate was agreed.

## Reproduce

```bash
cd artifacts/canary && pnpm run canary run 15-omnia-cross-token-route
```

**Expected:** Same-asset forwarding requires matching token ids. A cross-asset hop requires an authenticated swap quote with explicit input/output amounts, assets, expiry and rate limits.

**Actual:** Two HTLCs with different token ids are compared by amount alone and the forward is admitted.

**Evidence:**

- packages/omnia-relay/src/forwarder.ts:206-218 — next.amount > inHtlc.amount, no token comparison

## Where to fix

- `packages/omnia-relay/src/forwarder.ts`

### Approach

Require token equality for ordinary forwarding. Add an explicit cross-token branch that consumes a signed swap quote (input asset/amount, output asset/amount, rate, expiry, max slippage) and journals it with the link.

## Constraints (do not violate)

- Never compare amounts across assets as a safety check.
- A cross-token hop without a verified quote must be refused.
- Journal the quote reference so recovery can re-check it.

## Acceptance criteria

- [ ] A same-asset forward with mismatched token ids is refused.
- [ ] A cross-token forward without a verified quote is refused.
- [ ] The journal records the rate and quote used.
