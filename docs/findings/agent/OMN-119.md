# OMN-119 — A malformed routing envelope is interpreted as a final destination

**Kind:** sdk-defect  
**Severity:** high  
**Status:** open  
**Packages:** `@totemsdk/omnia-router`
**Observed versions:** @totemsdk/omnia-router@0.6.0
**Origin:** Omnia adversarial audit — 26 November 2026 @ `c818f5e` (verified in source)

> reporter id OMN-117
**Source:** `Omnia adversarial audit — 26 November 2026, reporter finding OMN-117 (omnia-router/src/forward.ts:75-94)`

## Context

decode catches JSON parse failures and returns kind final, treating malformed input as an instruction that this node is the recipient.

## Impact

A corrupted or hostile envelope can turn an intermediary into the recipient of a payment it did not earn.

## Reproduce

```bash
pnpm --filter @totemsdk/omnia-router test
```

**Expected:** Malformed input produces an invalid-envelope error.

**Actual:** Parse failure becomes final.

**Evidence:**

- forward.ts:75-94

## Where to fix


### Approach

Return a distinct invalid-envelope result and make callers refuse it.

## Constraints (do not violate)

- Keep a genuinely final hop working.
- Do not let the resolver fulfil on an invalid envelope.

## Acceptance criteria

- [ ] Malformed input is rejected.
- [ ] A final hop still settles.
