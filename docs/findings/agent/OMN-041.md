# OMN-041 — The host could issue active VTXOs without verified on-chain backing

**Kind:** sdk-defect  
**Severity:** high  
**Status:** fixed  
**Packages:** `@totemsdk/omnia-host`, `@totemsdk/omnia-vtxo`
**Observed versions:** @totemsdk/omnia@3.0.0, @totemsdk/omnia-host@0.14.0, @totemsdk/omnia-factory@0.7.2, @totemsdk/omnia-vtxo@0.9.0, @totemsdk/omnia-pool@0.6.0, @totemsdk/liquidity-bond@0.4.0, @totemsdk/omnia-router@0.4.2, @totemsdk/tx-builder@0.7.0
**Origin:** Totem Edge Omnia whole-family re-audit, 2026-11-17 @ `c81af31` (verified in source)
**Source:** `Deeper Omnia host audit, 2026-11-18 (verified against 51aed956)`

## Context

createVtxoPool accepted a caller-declared totalCapacity without funding proof, and mintVtxo persisted an active VTXO without verifying pool backing or operator authorization. Pool creation now requires a confirmed, unspent coin covering the capacity; mints are conserved against that backing and stay provisional until the operator co-signs the receipt.

## Impact

The local ledger could represent transferable liabilities with no on-chain pool coin behind them.

## Reproduce

```bash
pnpm --filter @totemsdk/omnia-host test
```

**Expected:** A VTXO becomes active only after confirmed pool backing and the operator receipt.

**Actual:** Fixed: backing is chain-verified, mints are conserved, provisional until the receipt is signed.

**Evidence:**

- packages/omnia-host/src/api/methods.ts createVtxoPool/mintVtxo/submitVtxoReceipt
- packages/omnia-vtxo/src/types.ts VtxoPoolBacking

## Where to fix

- `packages/omnia-host/src/api/methods.ts`
- `packages/omnia-vtxo/src/types.ts`

### Approach

Separate provisional issuance from transferable claims; require confirmed backing, conservation and the operator receipt before active.

## Constraints (do not violate)

- Never advertise unbacked VTXOs as redeemable.
- Re-verify the backing coin is unspent at mint time.

## Acceptance criteria

- [ ] An unfunded pool is rejected.
- [ ] Capacity above the backing coin is rejected.
- [ ] Mints stay provisional until co-signed.

## Tests that prove it
