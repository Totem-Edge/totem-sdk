# OMN-036 — Automatic channel funding selection compares atoms with decimal MINIMA

**Kind:** sdk-defect  
**Severity:** high  
**Status:** fixed  
**Packages:** `@totemsdk/omnia-host`, `@totemsdk/tx-builder`
**Observed versions:** @totemsdk/omnia@3.0.0, @totemsdk/omnia-host@0.14.0, @totemsdk/omnia-factory@0.7.2, @totemsdk/omnia-vtxo@0.9.0, @totemsdk/omnia-pool@0.6.0, @totemsdk/liquidity-bond@0.4.0, @totemsdk/omnia-router@0.4.2, @totemsdk/tx-builder@0.7.0
**Origin:** Totem Edge Omnia whole-family re-audit, 2026-11-17 @ `c81af31` (verified in source)
**Source:** `Deeper Omnia host audit, 2026-11-18 (verified against 51aed956)`

## Context

selectFundingCoin passed req.targetAmount.toString() (an atom count) to CoinSelectionService, which parses decimal MINIMA, so a 0.2 MINIMA target became roughly 2e43 MINIMA. The caller then used only selectedCoins[0]. The host now converts the target with atomsToAmount and picks a single coin that covers it; multi-input funding is reported explicitly instead of silently truncated.

## Impact

Automatic channel funding could fail with a false insufficient-funds result, and multi-coin selection was silently dropped.

## Reproduce

```bash
pnpm --filter @totemsdk/omnia-host test
```

**Expected:** A 0.2 MINIMA target selects a coin covering 0.2 MINIMA.

**Actual:** Fixed: the target crosses the boundary as decimal text and one sufficient coin is chosen; multi-input selection raises an explicit error.

**Evidence:**

- packages/omnia-host/src/api/methods.ts selectFundingCoin
- packages/tx-builder/src/coin-selection.ts selectCoins

## Where to fix

- `packages/omnia-host/src/api/methods.ts`

### Approach

Convert the atom target back to decimal MINIMA at the selection boundary and require one coin that covers the target, with an explicit multi-input error.

## Constraints (do not violate)

- Do not drop selected inputs silently.
- Never pass an atom integer to a decimal-MINIMA API.

## Acceptance criteria

- [ ] A fractional target selects a sufficient single coin.
- [ ] Multi-input selection fails explicitly.
