# OMN-043 — Live liquidity allocation targets were exposed but not wired to execution

**Kind:** sdk-defect  
**Severity:** medium  
**Status:** fixed  
**Packages:** `@totemsdk/omnia-host`, `@totemsdk/omnia-pool`
**Observed versions:** @totemsdk/omnia@3.0.0, @totemsdk/omnia-host@0.14.0, @totemsdk/omnia-factory@0.7.2, @totemsdk/omnia-vtxo@0.9.0, @totemsdk/omnia-pool@0.6.0, @totemsdk/liquidity-bond@0.4.0, @totemsdk/omnia-router@0.4.2, @totemsdk/tx-builder@0.7.0
**Origin:** Totem Edge Omnia whole-family re-audit, 2026-11-17 @ `c81af31` (verified in source)
**Source:** `Deeper Omnia host audit, 2026-11-18 (verified against 51aed956)`

## Context

allocatePositionCapital requires an execution context for channel/factory/router/VTXO targets, but the host RPC called it without one, so only reserve worked. The host now builds the router and VTXO ports from its own state, accepts injected channel/factory ports, and rejects any target it cannot execute before accounting is touched.

## Impact

Advertised allocation types failed through the host API; the unit test covered only reserve.

## Reproduce

```bash
pnpm --filter @totemsdk/omnia-host test
```

**Expected:** Every advertised target executes with its execution port or is rejected at request validation.

**Actual:** Fixed: router/VTXO execute; channel/factory require injected ports; unknown targets are rejected.

**Evidence:**

- packages/omnia-host/src/api/methods.ts allocatePoolCapital/allocationExecutionContext
- packages/omnia-pool/src/allocate.ts target requirements

## Where to fix

- `packages/omnia-host/src/api/methods.ts`
- `packages/omnia-host/src/lifecycle.ts`

### Approach

Inject live execution ports, execute each target, and fail validation before any accounting mutation.

## Constraints (do not violate)

- Do not advertise unsupported targets.
- Accounting is only updated after execution succeeds.

## Acceptance criteria

- [ ] Router and VTXO targets execute end-to-end.
- [ ] An unconfigured channel target is rejected without accounting changes.

## Tests that prove it

- `tests/unit/omnia-host/src/__tests__/allocation-targets.test.ts`
