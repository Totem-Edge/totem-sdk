# OMN-082 — Rollback silently drops a locked HTLC when its channel or lease provider is missing

**Kind:** sdk-defect  
**Severity:** high  
**Status:** fixed  
**Packages:** `@totemsdk/omnia-router`
**Tracked as:** `CAN-015` — this id is the audit's alias; the canonical entry owns the fix.
**Observed versions:** @totemsdk/omnia-router@0.5.0
**Origin:** Omnia SDK audit — 25 November 2026 @ `9f882c8` (verified in source)
**Source:** `Omnia SDK audit — 25 November 2026, reporter finding OMN-080`

## Context

cancelHtlcs() skips a locked HTLC entirely when the channel is absent from the map or no lease provider is registered for it. It does not add the obligation to pendingRefunds, so the caller is told that rollback completed while the lock remains.

## Impact

Liquidity stays locked with no record. The caller receives a failure result that implies recovery, and no later pass reconciles the stranded HTLC. CAN-015 covers the early-timeout part of this path; the missing-dependency branch is still open.

## Reproduce

```bash
cd artifacts/canary && pnpm run canary run 23-chaos-recovery
```

**Expected:** Every lock that rollback could not release is reported to the caller and persisted for reconciliation.

**Actual:** With the lease provider removed from the map, cancelHtlcs returns without pushing a pendingRefund.

**Evidence:**

- packages/omnia-router/src/execute.ts:65 — if (!ch || !lp) continue
- packages/omnia-router/src/execute.ts:67-82 — only a thrown timeoutHTLC becomes a pendingRefund

## Where to fix

- `packages/omnia-router/src/execute.ts`

### Approach

Treat a missing channel or lease provider as an unresolved refund obligation: record it with the reason, surface it in pendingRefunds, and make it reconcilable once the dependency is available.

## Constraints (do not violate)

- Do not silently skip any locked HTLC.
- Keep the existing pendingRefunds shape and reason field.
- A rollback that leaves locks behind must not report a clean failure.

## Acceptance criteria

- [ ] A lock with a missing channel or lease provider appears in pendingRefunds.
- [ ] The failed result carries the unresolved obligations.
- [ ] Reconciliation can release the lock once the dependency returns.
