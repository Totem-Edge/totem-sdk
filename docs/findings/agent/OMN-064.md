# OMN-064 — KISSVM CHECKSIG ignores its documented data and signature arguments

**Kind:** sdk-defect  
**Severity:** high  
**Status:** fixed  
**Packages:** `@totemsdk/kissvm`
**Observed versions:** @totemsdk/kissvm@0.6.0, @totemsdk/core@1.6.0
**Origin:** Totem Edge Omnia whole-family re-audit, 2026-11-17 @ `c81af31` (verified in source)
**Source:** `OMN-058 feasibility spike, 2026-11-18 (RFC-079)`

## Context

Minima documents and implements CHECKSIG(public_key data signature): exactly three HEX parameters, verified as TreeKey.verify(data, signature). The SDK evaluator ignored args[1]/args[2] and verified the witness signature over the transaction digest. TypeScript now enforces the reference semantics (tree signature, or a flat WOTS signature over the supplied data) and Rust/WASM does the same for the flat form; both reject 0/1-argument forms, zero-length operands and non-hex operands.

## Impact

Detached certificates could not be authenticated, so a contestable factory escape (OMN-058) was unimplementable. Scripts that passed locally under the witness-only form would have failed on a real node.

## Reproduce

```bash
pnpm --filter @totemsdk/kissvm test
```

**Expected:** CHECKSIG(pk data sig) verifies the supplied signature over the supplied data.

**Actual:** Fixed: the evaluator verifies the supplied data and signature. The parity suite measures TS against the Rust/WASM artifact on the same fixtures; the node leg is scripts/kissvm-node-parity.mjs.

**Evidence:**

- packages/kissvm/src/eval.ts evalChecksig
- packages/kissvm/src/parser.ts CHECKSIG parse
- tests/unit/kissvm/src/__tests__/factory-escape-feasibility.test.ts

## Where to fix

- `packages/kissvm/src/eval.ts`
- `packages/kissvm/src/types.ts`

### Approach

Implement the reference three-argument form while keeping SIGNEDBY as the witness path, and prove TS/Rust agreement with shared fixtures generated from real keys.

## Constraints (do not violate)

- Do not silently keep the current meaning under the documented signature.
- Cover both the witness path and the detached path with real signatures.

## Acceptance criteria

- [ ] CHECKSIG(pk data sig) returns true only for a valid signature over data.
- [ ] A stale or foreign certificate fails.
- [ ] The witness cannot change the verdict.
- [ ] 0/1-argument and zero-length forms are rejected.
- [ ] TypeScript and Rust/WASM agree on every supported fixture.
