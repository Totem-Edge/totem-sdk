# OMN-064 — KISSVM CHECKSIG ignores its documented data and signature arguments

**Kind:** sdk-defect  
**Severity:** high  
**Status:** open  
**Packages:** `@totemsdk/kissvm`
**Observed versions:** @totemsdk/kissvm@0.6.0, @totemsdk/core@1.6.0
**Origin:** Totem Edge Omnia whole-family re-audit, 2026-11-17 @ `c81af31` (verified in source)
**Source:** `OMN-058 feasibility spike, 2026-11-18 (RFC-079)`

## Context

Minima documents CHECKSIG(public_key data signature). packages/kissvm/src/eval.ts evaluates only args[0], looks up witness.signatures[publicKey] and verifies it against txCtx.txDigest; args[1] and args[2] are parsed and discarded. Two scripts that differ only in data/signature produce the same verdict.

## Impact

Any covenant that relies on verifying a detached certificate (for example a factory recovery certificate) cannot be expressed or tested with the SDK evaluator. This is a parity question, not evidence about node behaviour.

## Reproduce

```bash
pnpm --filter @totemsdk/kissvm test
```

**Expected:** CHECKSIG(pk data sig) verifies the supplied signature over the supplied data.

**Actual:** The evaluator verifies the witness signature over the transaction digest; data and sig are ignored.

**Evidence:**

- packages/kissvm/src/eval.ts evalChecksig
- packages/kissvm/src/parser.ts CHECKSIG parse
- tests/unit/kissvm/src/__tests__/factory-escape-feasibility.test.ts

## Where to fix

- `packages/kissvm/src/eval.ts`
- `packages/kissvm/src/types.ts`

### Approach

Implement the documented three-argument form (verify the parsed signature over the parsed data with the parsed key) while keeping the zero/one-argument witness form, then prove parity against a real Minima node and the Rust/WASM evaluator.

## Constraints (do not violate)

- Do not silently keep the current meaning under the documented signature.
- Cover both the witness path and the detached path with real signatures.

## Acceptance criteria

- [ ] CHECKSIG(pk data sig) returns true only for a valid signature over data.
- [ ] A stale/foreign certificate fails.
- [ ] Node, TS and Rust/WASM evaluators agree on the same fixture.
