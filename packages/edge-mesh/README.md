# @totemsdk/edge-mesh

Mesh framing and relay for constrained links — BLE, NFC taps, chunked LoRaWAN,
or anything packet-sized.

It is the transport half of [RFC-0018](https://github.com/Totem-Edge/hawk-node/blob/main/RFC-0018-BLE-MESH-SYNC.md):
fragmentation, reassembly, duplicate suppression and a bounded store-and-forward
queue. It knows nothing about blocks, coins or Minima; a Minima node frame is
just bytes to it.

## Install

```bash
npm install @totemsdk/edge-mesh
```

## What it does

- **Fragmentation** — splits a payload into packets that fit a link MTU. A
  Minima one-block IBD frame (314 bytes) is two packets at BLE MTU 185 and one
  at 512.
- **Reassembly** — CRC-checked, out-of-order and duplicate tolerant, with TTL
  expiry for half-built frames.
- **Store-and-forward** — bounded relay queue with 64-bit dedupe and a TTL, so
  a device that missed traffic can still catch a peer up later.
- **Stream framing** — splits a length-prefixed node stream into whole frames,
  for bridges that tunnel a node's P2P connection.

## Quick start

```ts
import { Fragmenter, Reassembler, StoreAndForward } from '@totemsdk/edge-mesh';

const fragmenter = new Fragmenter(185);          // BLE MTU
const packets = fragmenter.fragment(42, frame);  // Uint8Array[]

const reassembler = new Reassembler();
for (const packet of packets) {
  const frame = reassembler.add(packet, Date.now());
  if (frame) { /* whole payload */ }
}

const relay = new StoreAndForward(64 * 1024, 7, 5 * 60_000);
if (relay.add(frame, Date.now())) {
  for (const outgoing of relay.take(Date.now())) { /* send to peers */ }
}
```

## Wire format

```
magic 0xB7 | version 1 | msgId u16 | seq u16 | total u16 | crc16 u16 | payload
```

All fields big-endian; `crc16` is CRC-16/CCITT-FALSE over the payload. A corrupt
fragment is dropped and never assembled.

## Conformance

`test-vectors/mesh-v1.json` is generated by the C++ reference implementation in
`hawk-node/ble` and checked into this package. The TypeScript tests and the C++
tests both consume it, so a wire-format change in either language fails the
other's suite:

```bash
pnpm --filter @totemsdk/edge-mesh test
```

Regenerate after an intentional format change (node repo):

```bash
cmake --build build --target ble_gen_vectors && ./build/ble_gen_vectors > ble/vectors/mesh-v1.json
```

## Limits

- Full-chain bootstrap over a constrained link is not viable; use it for tip and
  block propagation, short catch-up, and transaction relay.
- Links are untrusted: frames are opaque, and the node validates every block.
- Keep wallet material and RPC credentials off the mesh.
