# KISSVM Code Gaps

> Categories of KISSVM operators that SDK packages should be generating but currently are not. Remediation progress tracked against the [dead-code-inventory](../../docs/dead-code-inventory.md) and [remediation-plan](../../docs/remediation-plan.md).

## Evaluator gaps — closed

| Gap | Status | Fixed in |
|-----|--------|----------|
| `@TOTIN` returns sum instead of count | ✅ | `eval.ts` |
| `@TOTOUT` returns sum instead of count | ✅ | `eval.ts` |
| `asMiniNumber` rejects hex strings | ✅ | `eval.ts` |
| `INC` / `DEC` missing | ✅ | `eval.ts` — builtin functions |
| `BITGET` / `BITSET` missing | ✅ | `eval.ts` — builtin functions |
| `FUNCTION` dynamic eval missing | ✅ | `eval.ts` — string-substitution + parse |
| `GET` tuple retrieval missing | ✅ | `eval.ts` — builtin; `vm.tuples` store |
| `LET (expr) = value` array syntax | ✅ | `parser.ts` — `STORE_TUPLE` AST node |
| `EXEC` doesn't decode hex scripts | ✅ | `eval.ts` — `hexToBytes` → `TextDecoder` |

## Per-package source gaps — not yet remediated

The following packages define off-chain business logic (TypeScript state machines, signature checks, etc.) but do not generate on-chain KISSVM scripts. Exact line-level remediation actions per package are documented in [`../../docs/remediation-plan.md`](../../docs/remediation-plan.md).

### 1. On-chain state machines (`STATE`/`PREVSTATE`/`SAMESTATE`)

| Package | Statuses | Script needed |
|---------|----------|---------------|
| governance | `draft→active→passed→failed→executed→cancelled→expired` | State machine with block-height windows |
| liquidity-bond | 13 position statuses (7 never assigned) | Position lifecycle + lock-term enforcement |
| provider-bond | 7 bond statuses | Bond lifecycle enforce at UTXO level |
| industrial-action | `draft→committed→executed→failed→expired` | Commit-reveal integrity |
| wots-lease | `pending→active→expired→finalized→cancelled` | Block-based lease expiry |
| authority | `issued→active→revoked→expired` | Epoch-boundary mandate revocation |

### 2. Signature verification (`SIGNEDBY`/`MULTISIG`/`CHECKSIG`)

| Package | Off-chain verification | Script needed |
|---------|----------------------|---------------|
| governance | Proposal status transition authorization | Multi-sig threshold for passed→executed |
| liquidity-bond | Position transitions by role | Role-gated SIGNEDBY |
| provider-bond | Bond transitions by operator | Operator-gated transitions |
| industrial-action | Action authorization by participants | Participant MULTISIG |

### 3. Timelock enforcement (`@BLOCK`/`@COINAGE`)

| Package | Off-chain timing | Script needed |
|---------|------------------|---------------|
| governance | Voting window, proposal expiry | `@BLOCK GTE votingStart AND @BLOCK LTE votingEnd` |
| liquidity-bond | Lock term, min bond duration | `@COINAGE GTE minTerm` |
| provider-bond | Bond maturity period | `@COINAGE GTE maturity` |
| wots-lease | Lease duration | `@COINAGE GTE leaseTerm` |
| temporal | `temporal-framework-design.md` design exists | 6 primitives defined but not generated per-package |

### 4. Token & amount constraints (`@TOKENID`/`@AMOUNT`/`VERIFYOUT`)

| Package | Off-chain | Script needed |

| provider-bond | Bond amount validation | `ASSERT @AMOUNT GTE minBond` |

### 5. Replay protection (`INC`/nonce)
