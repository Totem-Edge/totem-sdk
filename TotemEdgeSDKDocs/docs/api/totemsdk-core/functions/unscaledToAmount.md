# Function: unscaledToAmount()

> **unscaledToAmount**(`unscaled`, `scale`): `string`

Render an unscaled integer at a given MiniNumber scale as decimal text.
`unscaledToAmount(2e43, 44)` → `"0.2"`.

## Parameters

### unscaled

`bigint`

### scale

`number`

## Returns

`string`
